The focused same-node repeat removes the earlier `gjfjh` imbalance and is valid for forced-policy comparison. Loading improved successful request throughput in all four C16 cells, in the 1K–4K C32 cells, and only the 1K C64 cell. It lost 15.8% at 8K/C32 and 7.0–21.5% at 2K–8K/C64. Losing cells had at least 3.45 derived deferred-lookup request-equivalents, while throughput-winning cells had at most 0.51; native waiting requests showed the same separation.

Do not select a new `minExternalReusableTokens` value from this batch. The preferred action changes with pressure, a throughput win is not always a TTFT-tail win, and the nominal GuideLLM prefix was only partly sourced externally. The next experiment should add one EPP-visible pending-work EWMA veto to the existing reusable-token value screen and compare that selective arm with forced load and forced recompute on the same grid.
