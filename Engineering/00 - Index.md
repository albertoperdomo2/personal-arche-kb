## How to add
- **Fixed a cluster/infra/code issue?** → new file in `Incidents/` using the [Incident Template](../Templates/Incident%20Template.md). Name it `YYYY-MM-DD - <short symptom>.md`.
- **Did the same fix twice?** → promote it to a `Runbooks/` procedure.
- **Learned something reusable?** → `Learnings/`.
- **Starting new project work?** → new file in `Projects/` from the [Project Note Template](../Templates/Project%20Note%20Template.md).
